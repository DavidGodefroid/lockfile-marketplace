# lockfile-marketplace

The official plugin marketplace of [lockfile](https://github.com/DavidGodefroid/lockfile).

A lockfile plugin answers exactly one yes/no question about one file, fixed
in its signed manifest (`plugin.toml`), and the only thing that leaves it is
`1` or `0`. lockfile runs it in a sandbox (Landlock, seccomp, rlimits) with
the file as read-only fd 3, no path, no network and no other input.

- `sdk/`: what a plugin's `main` calls (`sdk.Main`), and the conformance
  harness every plugin's tests run (`sdk/harness`).
- `plugins/<name>/`: one Go module per plugin, with its manifest and tests.
  Fixtures are generated by the tests; no real document is ever committed.

Plugins are reviewed (see `REVIEW.md`), built from the tagged source by CI,
signed with cosign keyless and listed in a signed `index.json` published on
GitHub Pages. lockfile verifies both signatures and the hashes before it
installs a plugin.

Run the tests without a local Go toolchain: `scripts/go.sh --sandbox go test ./sdk/...`.
